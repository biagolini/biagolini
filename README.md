# Hi, I'm Carlos Biagolini 👋

**AWS Cloud Solutions Architect @ OpsTeam (AWS Premier Partner) · AWS Community Builder (AI Engineering) · São Paulo, Brazil**

I'm Carlos Biagolini, an AWS Cloud Solutions Architect focused on Generative AI, serverless, and Well-Architected cloud design. I help teams adopt, optimize, and get long-term value from Amazon Web Services (AWS) by building scalable, secure, and cost-effective architectures aligned with the AWS Well-Architected Framework and FinOps.
